# RoundTable AI website

Product landing page, support, privacy policy and terms for RoundTable AI.

Site: https://wklken.me/roundtable-ai-site/

Edit `landing.html`, `landing.css` and `landing.js` for the homepage; edit `generate.py` for legal and support copy. Run `python3 generate.py` and commit source plus generated `docs/` files. GitHub Pages publishes `main` → `/docs`. No app source or credentials belong here.

The product image is a real app preview of a fictional side-project discussion. Interactive examples are labeled illustrations. The app is not released; keep availability copy accurate and only add a download link after release.
