115|¿En qué se diferencia de una sola respuesta de IA?
116|Tu pregunta se convierte en una conversación moderada. Las perspectivas intervienen por turnos, leen lo anterior y examinan las ventajas e inconvenientes. Después, el moderador crea un informe de decisión. Varias perspectivas no garantizan exactitud: verifica la información importante.
117|¿El acceso permanente incluye el uso de IA?
118|No. La compra única desbloquea conversaciones ilimitadas en la app. Tú aportas una conexión compatible y el proveedor cobra su uso por separado.
119|¿Qué ocurre después de las cinco conversaciones gratis?
120|La compra permanente opcional desbloquea más conversaciones. El historial existente y la exportación a Markdown siguen disponibles sin comprar. Cada conversación cuenta una vez al guardar su primer informe; continuarla no consume otro uso gratuito.
121|¿Puedo usarla para decisiones importantes?
122|Úsala para ordenar ideas y descubrir preguntas que vale la pena hacer. La IA puede equivocarse o tener sesgos. Verifica las afirmaciones importantes y consulta a profesionales cualificados cuando corresponda. Tú tomas la decisión final.

148|Política de privacidad — RoundTable AI
149|El historial permanece en tu Mac. Tras tu permiso, las solicitudes de IA van directamente a la conexión elegida.
150|Actualizado: 12 de septiembre de 2026. Esta política describe RoundTable AI para macOS, de Kunliang Wu.
151|Datos guardados en tu Mac
152|La app guarda localmente conversaciones, informes, configuración de expertos, conexiones de modelos y preferencias. No ofrece cuenta propia ni sincronización en la nube. Las claves API se cifran localmente y la clave de cifrado se guarda en el mismo Mac. Esto no cifra todo el historial. Protege tu Mac y tus copias de seguridad.
153|Datos enviados en solicitudes de IA
154|Al permitir una conexión, la app envía al destino los datos necesarios para descubrir modelos y generar respuestas. Pueden incluir pregunta, contexto, historial, respuestas previas, instrucciones de expertos y ajustes del modelo. La clave API sirve de autenticación. El proveedor también recibe datos habituales de conexión, como la IP. Las intervenciones posteriores pueden recibir el contenido anterior como contexto.
155|La pantalla de permiso identifica la conexión y su destino. Tú eliges el proveedor, incluido un destino local compatible cuando esté admitido. El desarrollador no opera un intermediario para estas solicitudes ni recibe conversaciones o claves mediante un servidor de la app.
156|Tratamiento del proveedor
157|Los proveedores aplican sus propias condiciones y políticas. La conservación, uso para entrenamiento, asociación a cuentas y países de tratamiento dependen del proveedor, destino y configuración de tu cuenta. La app no promete conservación cero ni impide guardar datos ya recibidos. Revisa la política antes de enviar información personal o confidencial.
158|Tus opciones
159|Puedes rechazar el permiso de IA, revisarlo en Ajustes → Modelos o retirarlo para impedir futuras solicitudes. Retirarlo no revierte envíos completados ni recupera solicitudes en curso. Puedes exportar informes y borrar conversaciones locales. Elimina aparte exportaciones y copias que no necesites. Contacta al proveedor por los datos que conserve.
160|Compras
161|Apple procesa compras y pagos. La app lee datos verificados de transacciones y derechos de StoreKit para desbloquear o restaurar funciones. El desarrollador no recibe datos de tarjetas de pago mediante la app. A los servicios de Apple se aplica su propia política de privacidad.
162|Otras actividades de red
163|Los iconos de proveedores pueden descargarse desde GitHub y almacenarse localmente. Las solicitudes revelan información normal de red al alojamiento, pero no claves API ni textos de conversación. Los enlaces externos usan el navegador. La app no incluye publicidad ni SDK de análisis de terceros.
164|Ayuda y este sitio
165|Al contactar con asistencia, el desarrollador recibe tu mensaje y los datos de contacto que facilites para atenderte. No envíes claves API ni contraseñas. Este sitio no tiene publicidad, scripts de análisis ni formularios para subir conversaciones. El alojamiento procesa solicitudes de red normales para mostrar las páginas. Tu elección de idioma se guarda en este navegador para futuras visitas.
