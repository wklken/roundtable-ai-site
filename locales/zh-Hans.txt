148|隐私政策 — Little Roundtable
149|讨论历史保存在你的 Mac。获得授权后，AI 请求直接发往你选择的模型连接。
150|更新日期：2026 年 9 月 12 日。本政策适用于 Kunliang Wu 提供的 Little Roundtable macOS App。
151|Mac 上存储的数据
152|App 在本地保存讨论、生成的报告、专家设置、模型连接和偏好。没有 App 账户或云同步服务。API Key 在本地加密，加密密钥保存在同一台 Mac 上。这不等于加密整个讨论历史，请妥善保护 Mac 和备份。
153|AI 请求发送的数据
154|你允许连接后，App 会把模型发现和生成所需的信息直接发送到该端点，可能包含问题、背景、讨论历史、先前的模型回复、专家指令和模型设置。API Key 用于身份验证。服务商还会收到 IP 地址等常规连接信息。后续发言者可能收到先前讨论内容，以便理解上下文。
155|授权界面会标明连接和端点。服务商由你选择，也可使用受支持的兼容本地端点。开发者不代理这些请求，也不会通过 App 后端接收你的讨论或密钥。
156|服务商如何处理数据
157|服务商依据其条款和隐私政策处理请求。数据保留、训练用途、账户关联和处理国家取决于服务商、端点及账户设置。App 不承诺零保留，也无法阻止服务商保留已收到的数据。发送个人或机密信息前，请查看其政策。
158|你的选择
159|你可以拒绝 AI 授权，在「设置 → 模型」中查看或撤回授权以阻止后续请求。撤回不会撤销已完成的传输或召回正在进行的请求。可在 App 内导出报告、删除本地讨论；不再需要的导出文件和备份应单独删除。对服务商保留数据的请求，请联系服务商。
160|购买
161|Apple 处理购买和付款。App 读取经过验证的 StoreKit 交易和权益信息，用于解锁或恢复功能。开发者不会通过 App 收到你的银行卡信息。Apple 服务适用其自身隐私政策。
162|其他网络活动
163|服务商图标可能从 GitHub 下载并缓存到本地。这些请求会向托管服务披露常规网络信息，不包含 API Key 或讨论文本。外部链接通过浏览器打开。App 不包含广告或第三方分析 SDK。
164|支持和本站
165|联系支持时，开发者会收到你的消息及你选择提供的联系信息，用于处理请求。请勿发送 API Key 或密码。本站没有广告、分析脚本或讨论上传表单。托管服务会处理用于展示页面的常规网络请求。 本站会在此浏览器中保存你的语言选择，以便下次使用。
