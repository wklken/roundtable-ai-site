Little Roundtable支援隱私條款

Little Roundtable · macOS

支援

從一個問題開始。補充背景、選擇視角，然後檢視討論與決策報告。

連接模型

開啟「設定 → 模型」，新增相容的服務供應商、端點、API Key 和模型。測試或生成之前，請閱讀 AI 資料共享提示並允許連接。模型費用由服務供應商收取，與 App 購買分開。

請求失敗或卡住

檢查端點、所選模型、API Key、服務供應商餘額和網路連接。如果曾拒絕或撤回授權，請在「設定 → 模型」中檢查 AI 權限。修改背景前先暫停討論，準備好後繼續。服務供應商故障或限流可能中斷生成。

恢復終身權限

開啟「設定 → 終身解鎖」，選擇「恢復購買」，使用當時購買的 Apple 帳號。App 通過 StoreKit 驗證購買。退款或被撤銷的購買將不再提供無限討論權限。

討論和歷史記錄

終身權限可解鎖無限討論。你可以回顧討論歷史，並將報告匯出為 Markdown。

聯繫支援

發送郵件至 wklken@gmail.com 獲取 App 支援。

請提供 macOS 版本、App 版本、預期行為和錯誤資訊。截圖或記錄檔中請移除 API Key、密碼和私密討論內容。
