Little Roundtable支援隱私條款

Little Roundtable · macOS

隱私政策

討論歷史儲存在你的 Mac。獲得授權後，AI 請求直接發往你選擇的模型連接。

更新日期：2026 年 9 月 12 日。本政策適用於 Kunliang Wu 提供的 Little Roundtable macOS App。

Mac 上儲存的資料

App 在本地儲存討論、生成的報告、專家設定、模型連接和偏好。沒有 App 帳號或雲同步服務。API Key 在本地加密，加密金鑰儲存在同一台 Mac 上。這不等於加密整個討論歷史，請妥善保護 Mac 和備份。

AI 請求發送的資料

你允許連接後，App 會把模型發現和生成所需的資訊直接發送到該端點，可能包含問題、背景、討論歷史、先前的模型回覆、專家指令和模型設定。API Key 用於身分驗證。服務供應商還會收到 IP 地址等常規連接資訊。後續發言者可能收到先前討論內容，以便理解上下文。

授權介面會標明連接和端點。服務供應商由你選擇，也可使用受支援的相容本地端點。開發者不代理這些請求，也不會通過 App 後端接收你的討論或金鑰。

服務供應商如何處理資料

服務供應商依據其條款和隱私政策處理請求。資料保留、訓練用途、帳號關聯和處理國家取決於服務供應商、端點及帳號設定。App 不承諾零保留，也無法阻止服務供應商保留已收到的資料。發送個人或機密資訊前，請檢視其政策。

你的選擇

你可以拒絕 AI 授權，在「設定 → 模型」中檢視或撤回授權以阻止後續請求。撤回不會撤銷已完成的傳輸或召回正在進行的請求。可在 App 內匯出報告、刪除本地討論；不再需要的匯出檔案和備份應單獨刪除。對服務供應商保留資料的請求，請聯繫服務供應商。

購買

Apple 處理購買和付款。App 讀取經過驗證的 StoreKit 交易和權益資訊，用於解鎖或恢復功能。開發者不會通過 App 收到你的銀行卡資訊。Apple 服務適用其自身隱私政策。

其他網路活動

服務供應商圖示可能從 GitHub 下載並快取到本地。這些請求會向託管服務披露常規網路資訊，不包含 API Key 或討論文字。外部連結通過瀏覽器開啟。App 不包含廣告或第三方分析 SDK。

支援和本站

聯繫支援時，開發者會收到你的訊息及你選擇提供的聯繫資訊，用於處理請求。請勿發送 API Key 或密碼。本站沒有廣告、分析腳本或討論上傳表單。託管服務會處理用於展示頁面的常規網路請求。 本站會在此瀏覽器中儲存你的語言選擇，以便下次使用。
