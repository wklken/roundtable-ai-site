라이선스

평생 이용권

일회성 비소모성 구매로 앱 내 토론을 무제한으로 해제합니다. 자동 갱신 구독이 아닙니다. 구매 전 App Store에서 지역 가격과 세금을 표시합니다. 같은 Apple 계정으로 복원할 수 있습니다. 환불 또는 취소 시 유료 권한이 제거됩니다.

모델 크레딧이나 호스팅 AI 서비스는 포함되지 않으며 타사 제공업체의 지속적인 이용 가능성을 보장하지 않습니다. 필요한 API 키와 별도 요금은 직접 부담합니다. 구매 없이도 기록과 Markdown 내보내기를 이용할 수 있습니다.

AI 출력과 결정

관점과 진행자 보고서는 AI가 생성하며 독립적인 인간 전문가가 아닙니다. 오류, 근거 없는 전제, 공통 편향이 있을 수 있습니다. 중요한 정보는 확인하고 직접 판단하세요. 의료·법률·금융 등 전문가 조언을 대신하지 않으며 긴급 서비스도 아닙니다.

콘텐츠와 연결

제공한 콘텐츠의 권리는 사용자에게 있습니다. 사용하고 선택한 제공업체와 공유할 권리가 있는 내용만 제출하세요. 업체 약관과 관련 법을 준수하세요. 적절한 엔드포인트 선택과 API 키 보호는 사용자의 책임입니다.
