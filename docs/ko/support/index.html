지원

질문부터 시작하세요. 배경과 관점을 더한 뒤 토론과 의사결정 보고서를 확인하세요.

모델 연결

설정 → 모델에서 호환 제공업체, 엔드포인트, API 키, 모델을 추가하세요. 테스트나 생성 전에 AI 데이터 공유 안내를 읽고 연결을 허용하세요. 모델 요금은 앱 구매와 별도로 제공업체가 청구합니다.

요청 실패 또는 멈춤

엔드포인트, 모델, API 키, 잔액, 네트워크를 확인하세요. 이전에 권한을 거부하거나 철회했다면 설정 → 모델에서 AI 권한을 확인하세요. 배경을 수정하기 전에 토론을 일시 정지하고 준비되면 이어가세요. 제공업체 장애나 요청 제한으로 생성이 중단될 수 있습니다.

평생 이용권 복원

설정 → 평생 이용권에서 구매 복원을 선택하고 구매 당시의 Apple 계정을 사용하세요. 앱은 StoreKit으로 구매를 검증합니다. 환불되거나 취소된 구매는 무제한 토론 권한을 제공하지 않습니다.

무료 토론과 기록

토론 다섯 번을 무료로 완료할 수 있습니다. 첫 보고서 저장 시 한 번으로 계산하고 같은 토론을 이어가면 추가 차감하지 않습니다. 구매 없이도 기존 기록과 Markdown 내보내기를 이용할 수 있습니다.
