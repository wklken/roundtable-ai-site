Little Roundtable · macOS

개인정보 처리방침

토론 기록은 Mac에 보관됩니다. 허용한 뒤 AI 요청은 선택한 모델 연결로 직접 전송됩니다.

최종 업데이트: 2026년 9월 12일. 이 방침은 Kunliang Wu가 제공하는 macOS 앱 Little Roundtable에 적용됩니다.

Mac에 저장되는 데이터

대화, 보고서, 전문가 설정, 모델 연결 및 환경설정을 로컬에 저장합니다. 앱 계정이나 클라우드 동기화는 제공하지 않습니다. API 키는 로컬에서 암호화되며 암호화 키도 같은 Mac에 저장됩니다. 전체 대화 기록을 암호화하는 것은 아니므로 Mac과 백업을 보호하세요.

AI 요청으로 전송되는 데이터

연결을 허용하면 모델 검색과 생성에 필요한 정보를 엔드포인트로 직접 보냅니다. 질문, 배경, 대화 기록, 이전 모델 응답, 전문가 지시, 모델 설정이 포함될 수 있습니다. API 키는 인증에 쓰입니다. 제공업체는 IP 주소 등 일반 연결 정보도 받습니다. 뒤의 발언자는 맥락을 이해하기 위해 이전 토론 내용을 받을 수 있습니다.

동의 화면에 연결과 엔드포인트가 표시됩니다. 제공업체는 직접 선택하며 호환되는 로컬 엔드포인트도 지원됩니다. 개발자는 요청을 중계하지 않으며 앱 백엔드로 대화나 키를 받지 않습니다.

제공업체의 처리

각 제공업체의 약관과 개인정보 정책에 따라 처리됩니다. 보관, 학습 사용, 계정 연결 및 처리 국가는 제공업체, 엔드포인트, 계정 설정에 따라 다릅니다. 앱은 무보관을 보장하거나 이미 받은 데이터의 보관을 막지 못합니다. 개인 또는 기밀 정보 전송 전에 정책을 확인하세요.

사용자의 선택

AI 권한을 거부하거나 설정 → 모델에서 확인·철회하여 이후 요청을 막을 수 있습니다. 철회는 완료된 전송이나 진행 중인 요청을 되돌리지 않습니다. 앱에서 보고서를 내보내고 로컬 대화를 삭제할 수 있습니다. 불필요한 내보내기 파일과 백업은 별도로 삭제하세요. 제공업체 보관 데이터는 해당 업체에 문의하세요.

구매

Apple이 구매와 결제를 처리합니다. 앱은 검증된 StoreKit 거래 및 이용 권한으로 기능을 해제하거나 복원합니다. 개발자는 앱을 통해 결제 카드 정보를 받지 않습니다. Apple 서비스에는 Apple의 개인정보 정책이 적용됩니다.

기타 네트워크 활동

제공업체 아이콘을 GitHub에서 내려받아 로컬에 캐시할 수 있습니다. 이 요청은 호스팅 서비스에 일반 네트워크 정보를 전달하지만 API 키나 토론 본문은 포함하지 않습니다. 외부 링크는 브라우저로 열립니다. 광고나 타사 분석 SDK는 없습니다.

지원 및 이 웹사이트

지원에 문의하면 개발자는 요청을 처리하기 위해 메시지와 직접 제공한 연락처를 받습니다. API 키나 암호는 보내지 마세요. 이 사이트에는 광고, 분석 스크립트, 대화 업로드 양식이 없습니다. 호스팅 서비스는 페이지 제공을 위한 일반 요청을 처리합니다. 선택한 언어는 다음 방문에 사용하도록 이 브라우저에 저장됩니다.
