Little Roundtable · macOS

Política de privacidad

El historial permanece en tu Mac. Tras tu permiso, las solicitudes de IA van directamente a la conexión elegida.

Actualizado: 12 de septiembre de 2026. Esta política describe Little Roundtable para macOS, de Kunliang Wu.

Datos guardados en tu Mac

La app guarda localmente conversaciones, informes, configuración de expertos, conexiones de modelos y preferencias. No ofrece cuenta propia ni sincronización en la nube. Las claves API se cifran localmente y la clave de cifrado se guarda en el mismo Mac. Esto no cifra todo el historial. Protege tu Mac y tus copias de seguridad.

Datos enviados en solicitudes de IA

Al permitir una conexión, la app envía al destino los datos necesarios para descubrir modelos y generar respuestas. Pueden incluir pregunta, contexto, historial, respuestas previas, instrucciones de expertos y ajustes del modelo. La clave API sirve de autenticación. El proveedor también recibe datos habituales de conexión, como la IP. Las intervenciones posteriores pueden recibir el contenido anterior como contexto.

La pantalla de permiso identifica la conexión y su destino. Tú eliges el proveedor, incluido un destino local compatible cuando esté admitido. El desarrollador no opera un intermediario para estas solicitudes ni recibe conversaciones o claves mediante un servidor de la app.

Tratamiento del proveedor

Los proveedores aplican sus propias condiciones y políticas. La conservación, uso para entrenamiento, asociación a cuentas y países de tratamiento dependen del proveedor, destino y configuración de tu cuenta. La app no promete conservación cero ni impide guardar datos ya recibidos. Revisa la política antes de enviar información personal o confidencial.

Tus opciones

Puedes rechazar el permiso de IA, revisarlo en Ajustes → Modelos o retirarlo para impedir futuras solicitudes. Retirarlo no revierte envíos completados ni recupera solicitudes en curso. Puedes exportar informes y borrar conversaciones locales. Elimina aparte exportaciones y copias que no necesites. Contacta al proveedor por los datos que conserve.

Compras

Apple procesa compras y pagos. La app lee datos verificados de transacciones y derechos de StoreKit para desbloquear o restaurar funciones. El desarrollador no recibe datos de tarjetas de pago mediante la app. A los servicios de Apple se aplica su propia política de privacidad.

Otras actividades de red

Los iconos de proveedores pueden descargarse desde GitHub y almacenarse localmente. Las solicitudes revelan información normal de red al alojamiento, pero no claves API ni textos de conversación. Los enlaces externos usan el navegador. La app no incluye publicidad ni SDK de análisis de terceros.

Ayuda y este sitio

Al contactar con asistencia, el desarrollador recibe tu mensaje y los datos de contacto que facilites para atenderte. No envíes claves API ni contraseñas. Este sitio no tiene publicidad, scripts de análisis ni formularios para subir conversaciones. El alojamiento procesa solicitudes de red normales para mostrar las páginas. Tu elección de idioma se guarda en este navegador para futuras visitas.
