Little Roundtable · macOS

プライバシーポリシー

議論の履歴は Mac に保存されます。許可後、AI リクエストは選択したモデル接続先へ直接送信されます。

更新日：2026年9月12日。本方針は Kunliang Wu が提供する macOS アプリ Little Roundtable に適用されます。

Mac に保存するデータ

会話、レポート、専門家設定、モデル接続、環境設定をローカル保存します。アプリアカウントやクラウド同期はありません。API キーはローカルで暗号化し、暗号鍵も同じ Mac に保存します。会話履歴全体は暗号化されないため、Mac とバックアップを適切に保護してください。

AI リクエストで送るデータ

接続を許可すると、モデルの検出や生成に必要な情報を接続先へ直接送ります。問い、背景、会話履歴、以前のモデル回答、専門家への指示、モデル設定を含む場合があります。API キーは認証に使用し、プロバイダーは IP アドレスなどの通常の接続情報も受け取ります。後の発言者には文脈理解のために以前の議論を送る場合があります。

許可画面で接続と接続先を示します。プロバイダーはご自身で選択でき、対応するローカル接続先も利用できます。開発者はリクエストを中継せず、アプリのバックエンド経由で会話やキーを受信しません。

プロバイダーによる処理

各社の規約とプライバシーポリシーに従って処理されます。保管、学習への使用、アカウントとの関連付け、処理国は接続先やアカウント設定などで異なります。アプリは保管ゼロを保証せず、送信済みデータの保持を防げません。個人情報や機密情報を送る前に方針を確認してください。

選べること

AI の許可を拒否し、「設定 → モデル」で確認・取り消しできます。取り消しは今後のリクエストを防ぎますが、完了した送信や実行中のリクエストは取り消せません。アプリでレポートを書き出し、ローカル会話を削除できます。不要な書き出しファイルやバックアップは別途削除してください。プロバイダー保管データについては各社にお問い合わせください。

購入

購入と支払いは Apple が処理します。アプリは検証済みの StoreKit 取引・権利情報で機能を解除・復元します。開発者はアプリ経由でカード情報を受け取りません。Apple のサービスには同社のプライバシーポリシーが適用されます。

その他のネットワーク通信

プロバイダーのアイコンを GitHub から取得しローカルに保存する場合があります。通常の通信情報はホスティング先に送られますが、API キーや議論の本文は含みません。外部リンクはブラウザーで開きます。広告や第三者の分析 SDK は含みません。

サポートと本サイト

サポートへ連絡すると、開発者は対応のためにメッセージとご提供の連絡先を受け取ります。API キーやパスワードを送らないでください。本サイトに広告、分析スクリプト、会話アップロード機能はありません。ホスティング先はページ配信の通常の通信を処理します。 選んだ言語をこのブラウザーに保存し、次回の表示に使用します。
