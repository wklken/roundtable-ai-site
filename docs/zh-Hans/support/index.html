Little Roundtable · macOS

支持

从一个问题开始。补充背景、选择视角，然后查看讨论与决策报告。

连接模型

打开「设置 → 模型」，添加兼容的服务商、端点、API Key 和模型。测试或生成之前，请阅读 AI 数据共享提示并允许连接。模型费用由服务商收取，与 App 购买分开。

请求失败或卡住

检查端点、所选模型、API Key、服务商余额和网络连接。如果曾拒绝或撤回授权，请在「设置 → 模型」中检查 AI 权限。修改背景前先暂停讨论，准备好后继续。服务商故障或限流可能中断生成。

恢复终身权限

打开「设置 → 终身解锁」，选择「恢复购买」，使用当时购买的 Apple 账户。App 通过 StoreKit 验证购买。退款或被撤销的购买将不再提供无限讨论权限。

讨论和历史记录

终身权限可解锁无限讨论。你可以回顾讨论历史，并将报告导出为 Markdown。

联系支持

发送邮件至 wklken@gmail.com 获取 App 支持。

请提供 macOS 版本、App 版本、预期行为和错误信息。截图或日志中请移除 API Key、密码和私密讨论内容。
